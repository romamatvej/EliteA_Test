# EliteA_Test — CLI-викторина (test-app)

[![build](https://img.shields.io/badge/build-unknown-lightgrey)](https://example.com/) [![tests](https://img.shields.io/badge/tests-unknown-lightgrey)](https://example.com/)

Краткое описание
----------------
Небольшое Node.js CLI-приложение, реализующее интерактивную викторину/тест на основе данных в JSON. Проект расположен в каталоге `test-app/` и предназначен для запуска в терминале. Подходит как учебный пример для работы с вводом/выводом в Node.js, обработкой JSON и организацией CLI-приложений.

Особенности и учебные цели
--------------------------
- Простая командная утилита для проведения викторины из набора вопросов.
- Чтение вопросов из `data/questions.json`.
- Демонстрация модульной структуры (в папке `src/`).
- Практика работы с Node.js и созданием CLI-приложений.
- Подготовка к тестированию и автоматизации (скрипты в `package.json`).

Требования
----------
- Node.js >= 18 (рекомендуется).
- npm (входит в состав Node.js).

Установка
---------
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/romamatvej/EliteA_Test.git
   ```
2. Перейдите в каталог проекта и установите зависимости для CLI-приложения:
   ```bash
   cd EliteA_Test/test-app
   npm install
   ```

Как запускать
-------------
Есть несколько способов запустить CLI:

- Через npm-скрипт (если в package.json указан script "start"):
  ```bash
  cd EliteA_Test/test-app
  npm start
  ```

- Прямой запуск Node.js:
  ```bash
  node index.js
  # или (если вы запускаете из репозитория)
  node test-app/index.js
  ```

Сделать файл входной точки исполняемым (опционально)
---------------------------------------------------
Если вы хотите запускать файл как исполняемый скрипт (./index.js), выполните:
```bash
cd EliteA_Test/test-app
# убедитесь, что в первой строке есть shebang: #!/usr/bin/env node
chmod +x index.js
./index.js
```
Если shebang отсутствует, добавьте в начало `index.js`:
```bash
#!/usr/bin/env node
```

Примеры использования и ожидаемое поведение
------------------------------------------
- При запуске приложение загружает вопросы из `data/questions.json` и последовательно задаёт их пользователю в терминале.
- Ожидается ввод ответа (обычно число/строка) для каждого вопроса.
- В конце выводится итоговый результат (например, количество правильных ответов или процент).
- Пример:
  ```bash
  $ node test-app/index.js
  Вопрос 1: Какой цвет небо?
  1) Красный
  2) Синий
  3) Зелёный
  Ваш ответ: 2
  ...
  Результат: 8/10 правильных ответов (80%)
  ```

Структура репозитория
---------------------
Структура (на основе текущего содержимого):
```
EliteA_Test/
├─ test-app/
│  ├─ package.json        # зависимости и скрипты (start, test и т.д.)
│  ├─ index.js            # входная точка CLI
│  ├─ src/                # модули/логика приложения
│  │  └─ *.js
│  └─ data/
│     └─ questions.json   # набор вопросов для викторины
└─ README.md (этот файл)
```

Тестирование
------------
Если в `package.json` настроен скрипт `test`, запуск тестов:
```bash
cd EliteA_Test/test-app
npm test
```
Если тесты не настроены, добавьте тесты (например, с использованием Jest) и соответствующий скрипт:
```json
"scripts": {
  "test": "jest"
}
```
