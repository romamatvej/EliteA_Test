# CLI Quiz — интерактивная викторина в терминале

Краткое описание проекта
------------------------
Это простой CLI-приложение — интерактивная викторина, запускаемая в терминале с использованием Node.js (ES Modules). Проект предоставляет вопросы и категории из JSON-файла, задаёт вопросы пользователю через readline-подсказки, собирает ответы и выводит результаты. В утилитах содержатся функции для раскраски вывода в терминале и удобной обработки ввода.

Технологии и особенности
- Node.js (ES Modules), используется только стандартный API Node.js.
- Минимальное требование Node.js: >= 18.
- Вопросы и категории хранятся в data/questions.json.
- Командный вход/вывод реализован через readline и простой CLI-интерфейс.
- Простая система подсчёта баллов и итогов викторины.

Требования
---------
- Node.js версии 18 или новее.
- npm (или другой менеджер пакетов, совместимый с package.json).

Быстрый старт (установка и запуск)
---------------------------------
1. Клонируйте репозиторий и перейдите в директорию проекта:
   ```bash
   git clone <repository-url>
   cd test-app
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите приложение:
   ```bash
   npm start
   ```

Примечания:
- В package.json указано "type": "module", приложение использует современный синтаксис ES Modules.
- Если вы используете npx или похожий инструмент, можно запускать через `node`:
  ```bash
  node index.js
  ```
  но предпочтительный запуск — через `npm start`.

Использование (пример запуска и сценарий CLI)
---------------------------------------------
После запуска приложения (npm start) вам будет показано простое меню/последовательность подсказок:

Пример минимального взаимодействия (описательно):
- Приложение перечислит доступные категории вопросов, например:
  - 1) Общие знания
  - 2) История
  - 3) Программирование
- Вы вводите номер или имя категории и нажимаете Enter.
- Программа по очереди задаёт вопросы из выбранной категории; для каждого вопроса появляется текст и подсказка для ввода ответа.
- Вы вводите ответ и подтверждаете Enter.
- После прохождения всех вопросов показывается итог: количество правильных ответов, процент и, возможно, краткий отзыв.

Краткое описание сценария CLI:
- Запуск: npm start
- Выбор категории: ввод номера/названия
- Ответы на вопросы: ввод текста (или числа) и Enter
- Итог: отображение счёта, возможно цветное оформление с использованием утилит в src/colors.js

Конфигурация вопросов:
- Файл data/questions.json содержит категории и вопросы. Для расширения викторины можно редактировать или дополнять этот файл (формат JSON). Обновлённые вопросы будут использованы при следующем запуске.

Структура репозитория
---------------------
Важные файлы и их назначение:
- test-app/
  - index.js — точка входа CLI. Запускает процесс викторины и взаимодействие с пользователем.
  - package.json — метаданные проекта (name: quiz-cli), скрипты (start), указание типа module и требуемой версии Node.
  - src/quiz.js — класс Quiz, реализующий основную логику викторины (загрузка вопросов, порядок вопросов, подсчёт результатов).
  - src/input.js — утилиты для работы с вводом и подсказками через readline.
  - src/colors.js — утилиты для цветного форматирования вывода в терминале.
  - data/questions.json — JSON с категориями и вопросами (источник контента для викторины).
